# Easy Expense Tracker

A simple Python program to record income and expenses and calculate the remaining balance.

## Features
1. Add income
2. Add expense
3. View all records
4. Calculate total income, total expense, and balance
5. Save records in data.txt

## Requirements
- Python 3
- VS Code (recommended)

## How to run
Open this folder in VS Code. Select Terminal > New Terminal, then type:

    python main.py

## Python concepts
Variables, input/output, if/else, loops, functions, lists, dictionaries, classes, objects, and JSON file handling.

## Example
Income = Rs. 5000
Expense = Rs. 500
Balance = Rs. 4500
